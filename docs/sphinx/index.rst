PoloOS — Qt Dashboard
=====================

Qt6/QML instrument cluster for the Volkswagen Polo 9N3.

.. toctree::
   :maxdepth: 2
   :caption: Contents

Architecture
------------

- ``src/main.cpp`` — application entry point
- ``src/can/`` — CAN bus reader and vehicle data handler
- ``qml/`` — QML UI (pages, components, vehicle models)
- ``assets/`` — meshes, models, icons
